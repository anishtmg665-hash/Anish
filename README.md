# Birthday Magic Website

## Run it
1. Extract the ZIP.
2. Open `birthday-website/index.html` in a browser.
3. Internet is only needed for the Google font and sample gallery photos. The layout and interactions work locally without those.

## Personalize it
Open `script.js` and edit:
- `personName = "Someone Special"` to the birthday person's name.
- `birthdayDate = "2026-12-25"` to their birthday, in `YYYY-MM-DD` format.

Edit the message text directly in `index.html`.
To change gallery images, replace the image URLs in the four `<img src="...">` tags in `index.html` with your own image paths or URLs.

## Files
- `index.html` — page structure and text
- `style.css` — layout, colors, responsive design and animations
- `script.js` — confetti, menu, surprise message, countdown and generated birthday tune
